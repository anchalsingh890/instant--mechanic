# Instant Mechanic App

Mini Mechanic Service App built using Kotlin and Jetpack Compose.

## Features
- Browse nearby mechanics
- View mechanic details
- View ratings, location and services
- Request vehicle service
- Service request confirmation

## Technology
- Kotlin
- Android Studio
- Jetpack Compose
- Git & GitHub

## App Flow
Home → Mechanic Details → Request Service → Confirmation

## Project
This project was developed as part of the Mini Mechanic Service App assignment.
